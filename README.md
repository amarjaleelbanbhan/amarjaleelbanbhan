## About

I'm a Computer Science student and software engineer focused on secure AI systems, developer tools, and dependable product engineering. I like work where the result can be inspected: a working product, a reproducible experiment, or a fix with evidence behind it.

## Selected Work

### [RODIFT — Production](https://www.amarjaleel.me/work/rodift)

A field-operations platform I built across a Flutter mobile app, a Next.js dashboard, and a Supabase/PostGIS backend. The client owns the system, so the source and operational data remain private; the case study documents the architecture and its limits.

### [VeriPatch — Released](https://github.com/amarjaleelbanbhan/VeriPatch)

An npm security CLI that tests dependency fixes in an isolated copy, independently re-scans the result, runs the project's checks, and reports the evidence. [npm package](https://www.npmjs.com/package/veripatch)

### [KnowledgeGuard / EGB — Research](https://www.amarjaleel.me/research)

A controlled study of whether a RAG system can identify why its evidence is deficient and choose a useful repair. Oracle routing beat the strongest type-agnostic policy by 6.6 F1 points; routing on predicted types fell 0.064 F1 below that baseline. The research page documents the method, correction, and limitations. The source repository is private.

### [CortexWard — Pre-alpha](https://github.com/amarjaleelbanbhan/CortexWard)

A software-security research tool exploring evidence-based analysis and repair. Model output can propose a finding, but it cannot promote that finding to a higher verification state; the public roadmap distinguishes implemented work from planned work.
