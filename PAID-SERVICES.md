# Fixed-Scope Engineering Help

I take on small, clearly bounded software problems for founders, SaaS teams, agencies, and online businesses.

The goal is simple: **diagnose one real problem, deliver a verifiable result, and keep the scope small enough to move quickly.**

## 1. SaaS Post-Launch QA — $100 fixed

Best for a recently launched web app or AI product.

**Scope**
- Up to 10 critical user flows
- Signup/login/onboarding
- Forms and validation
- Dashboard loading/empty/error states
- Mobile + desktop pass
- Obvious browser console/network failures
- Developer-ready bug reports with severity and reproduction steps
- One regression checklist

**Boundary:** normal user-facing testing only. No intrusive security testing, exploitation, load testing, or production-data changes.

## 2. AI-Built / Vibe-Coded App Rescue — from $149

Best for apps built with tools such as Lovable, Bolt, Claude, Cursor, Replit, or similar workflows that mostly work but have one stubborn engineering problem.

Examples:
- React / Next.js runtime bugs
- Supabase auth, data, or permission issues
- API integration failures
- Stripe state/webhook problems
- Environment/configuration problems
- Vercel/deployment failures
- Broken loading, empty, or error states

I first reproduce and bound the issue. Larger rewrites are quoted separately.

## 3. Automation / Script Rescue — from $100

For one broken or repetitive workflow involving Python, JavaScript/TypeScript, Google Apps Script, CSV/JSON data, APIs, or small integrations.

Typical deliverable:
- Fix or automate one workflow
- Add validation/error handling where appropriate
- Test with supplied or synthetic data
- Source code
- Short handoff/run instructions

## 4. Website / App Bug Sprint — from $100

One reproducible bug in an existing product, such as:
- Mobile layout issue
- Form failure
- API/authentication error
- Build/deployment failure
- React/Next.js UI state bug
- Small data-processing defect

I confirm scope before starting. If the issue is much larger than it first appears, I stop and re-scope rather than silently expanding the bill.
